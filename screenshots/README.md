# Screenshots

This directory contains screenshots for the README.

To add screenshots:

1. Run the demo application
2. Take screenshots of:
   - `demo-interface.png` - Main interface with upload controls
   - `segmentation-results.png` - Grid view of segmented objects
   - `object-modal.png` - Modal dialog showing object details

3. Place the images in this directory

Recommended screenshot dimensions: 1200x800 or similar 3:2 aspect ratio
